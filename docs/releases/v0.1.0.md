# v0.1.0

正式版 v0.1.0 包含现有面板功能、Linux 双架构二进制、Docker 镜像包和一键部署脚本，适合在已有 Docker/Compose 的 1Panel 服务器安装面板。

```sh
curl -fsSL https://github.com/kexue-aihao/Traffic-Forwarding-Panel/releases/download/v0.1.0/install-docker.sh -o install-docker.sh && sudo bash install-docker.sh
```

输入域名和管理员密码后，脚本自动下载对应架构的镜像、校验 SHA256、配置容器和数据目录、初始化管理员，并等待健康检查。1Panel 反向代理目标默认 `http://127.0.0.1:18080`，启用 HTTPS/WebSocket、关闭代理缓存；管理员入口为 `/admin`。

- Linux amd64/arm64 原生构建的 Docker 镜像归档，可直接 `docker load`，无需镜像仓库账号。
- Compose 配置包含 SQLite 数据持久化、自动重启、日志轮转、非 root 用户及只读根文件系统。
- `/panel -healthcheck` 检查运行中的 HTTP 服务和数据库；初始化和探活进程互不混淆。
- 重复执行安装器保留已有账号、数据库和配置；支持离线包安装、自定义域名/端口/安装目录。
- 镜像包使用 `docker-SHA256SUMS`，二进制安装包使用 `SHA256SUMS`；不要混用。

部署说明：[Docker 与 1Panel](https://github.com/kexue-aihao/Traffic-Forwarding-Panel/blob/v0.1.0/docs/docker-deployment.md)。默认安装目录为 `/opt/traffic-forwarding-panel`，数据不存放在容器可写层。已有二进制部署需先备份并按文档迁移，脚本不会接管未知已有数据。

Docker 工作流在 amd64/arm64 Linux 上验证镜像导入、首次安装、HTTPS 反代登录、Secure Cookie、来源校验、SSE、重启后会话/数据保留和重复安装。该矩阵使用 Nginx 模拟 1Panel 的代理路径；未实际操作用户的 1Panel 服务器。

已知限制：当前租约续期可能关闭旧连接；连接连续性、容量/性能工作以及跨机/公网/真实支付验收继续按原指示等待后续安排。此次正式发布不改变这些实现与验收边界。


从 beta 版本升级：先备份，导入本版 Docker 镜像，将安装目录 `.env` 的 `TFP_IMAGE` 改为 `traffic-forwarding-panel:0.1.0-amd64` 或 `traffic-forwarding-panel:0.1.0-arm64`，再执行 `docker compose up -d --wait`。保留数据和域名配置，无需重新初始化管理员；安装器重复运行不会自动替换已有镜像版本。
