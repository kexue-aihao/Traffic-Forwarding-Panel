# v0.1.29

站点品牌设置和 Telegram 账号自助服务更新。

## 更新内容

- 站点名称继续同时用于站点和控制台；管理员可在站点设置上传 PNG/JPEG Logo，侧栏和浏览器图标同步更新，也可清除恢复默认图标。
- 复用现有 Telegram 机器人及 `/login` 绑定。已绑定用户可用 `/balance` 查询余额、`/traffic` 查询当前套餐流量。
- 登录页增加忘记密码流程。验证码发往已绑定的 Telegram 私聊，在网站输入验证码和新密码完成重置。验证码 10 分钟有效，每个账号 60 秒内最多发一次、每小时最多五次、最多尝试五次；成功后撤销旧会话和 API Token。

## 升级说明

启动时自动建立 Telegram 密码重置记录表。原有本人凭旧密码修改、管理员代重置及运维恢复流程保持不变。启用自助重置前，管理员需配置并启用 Telegram Bot，用户需在仍能登录时通过 `/login` 绑定。

## 验证与产物

通过 Go 测试、前端类型检查与构建、浏览器契约测试，以及 Chromium、Firefox、WebKit 的真实 Go/SQLite 联调。发布包包含 Linux amd64/arm64 二进制、Docker amd64/arm64 安装包、安装脚本和 SHA256 校验文件。
