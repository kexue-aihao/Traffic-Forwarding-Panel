# v0.1.23

本版加入 Telegram 通知与账号登录、人工充值流程，以及用户个人单端出口。

## 更新内容

- 运营与任务支持 Telegram Bot Token / Chat ID 通知，覆盖机器新增、首次上线、离线、恢复、充值到账和管理员财务收款；Token 不在列表明文显示。原飞书 / Discord / Webhook 配置保留兼容。
- 每个用户可创建自己的单端出口设备组、获取接入命令并添加自己的出口设备。同身份组的其他用户无法看到或使用该出口；服务端固定个人出口倍率为 1，不增加出口费用，原入口套餐和流量计费保持有效。
- 设备组页面补充普通用户接入出口设备的入口，出口页面可添加、编辑个人出口。
- 站点设置中的支付协议改为与注册策略一致的下拉选择，显示所选协议的配置项。
- Telegram /login：首次通过正常站点登录（含验证码）完成绑定，之后通过十分钟内有效、只能使用一次的临时链接免密登录。仅接受私聊，链接访问与消费分离，停用账号不能使用。
- Telegram /pay <网络> <人民币余额金额>：支持 trc20-usdt、erc20-usdt、bep20-usdt、polygon-usdt、trx、pol、eth、bnb；不带金额时显示网络地址和用法。
- 后台手动配置各网络收款地址、每币 CNY 汇率及暂停机器人；订单保留应付币数量。新增 Telegram 充值核实界面，管理员凭链上交易哈希确认后入账。
- 充值订单和意图原子创建，确认与钱包、账本、通知、审计同事务提交；重复 Telegram 更新、重复确认、同链交易哈希重复使用均有保护。
- 修复清空支付配置后重启被启动参数重新覆盖的问题。

## 升级与配置

升级前备份数据库。控制面 schema 升至 11，支付设置 namespace 升至 3，首次启动自动迁移。仍使用原有安装 / 升级脚本；安装包包含 Linux amd64 / arm64 与对应 Docker 离线包。

在站点设置填写 BotFather 生成的 Token、收款地址与汇率。命令机器人使用 long polling，同一 Token 不应被其他 webhook 或轮询进程占用；部署需允许访问 Telegram API。通知通道仍需在运营与任务中配置 Token 和收件 Chat ID，可选择机器事件及财务收款事件。

**手动地址模式需要管理员在链上核实币种、网络、数量、收款地址及确认数后入账，不是自动链上收款。** 汇率由管理员维护；未配置汇率的网络不允许下单。站点只保存收款地址，不接收钱包私钥。本轮没有真实 Bot Token 或真实转账，真实 Telegram 发送与实付仍待运营配置后验收。
