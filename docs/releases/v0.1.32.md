# v0.1.32

新增 `secure-direct` 安全直连承载：目标 Agent 直接终止 TLS 1.3，并在 TLS 会话内使用显式混淆层传输隧道数据。该承载仅允许 TCP，禁止 UDP、Mux、反向路由和链式路由。

## 更新内容

- 新增 `random-padding`、`timing-perturb` 和 `tls-mimic` 三种混淆策略，并在入口、目标 Agent、控制面规则和 OpenAPI 中完成配置传递与能力协商。
- 修复混淆层在 TCP 分片读取时的帧解析问题，增加长度校验、完整读写和剩余数据缓存。
- Agent 安装脚本新增 `secure-direct` 模式、混淆策略参数，以及 `provided`、`public-ip`、`auto` 三种证书模式。
- `public-ip` 和 `auto` 模式通过目标设备预装的 `certbot` 或 `acme.sh` 使用公网 CA 为 `-S` 指定的服务名申请证书；申请失败会中止安装，不会降级为明文。
- 面板接入向导、资源规则、设备能力和相关 API 文档支持安全直连与混淆配置。

## 升级说明

本版本不新增数据库迁移。使用 `secure-direct` 或混淆配置时，入口和目标 Agent 都需要升级到支持对应能力的版本，并使用相同的混淆策略与参数。公网证书模式要求 DNS、TCP/80 可达，并在目标设备预装 `certbot` 或 `acme.sh`；已有证书可继续使用 `provided` 模式。

## 验证与产物

本地验证包括 Go 测试、前端类型检查与构建、OpenAPI 生成一致性和 Git 差异检查。完整的竞态、三数据库、浏览器、Docker、Linux 跨机和公网证书验收由 CI 及部署环境完成。

发布包包含 Linux amd64/arm64 二进制、Docker amd64/arm64 安装包、安装脚本和 SHA256 校验文件。
