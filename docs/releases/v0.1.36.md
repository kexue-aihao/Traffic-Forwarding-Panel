# v0.1.36

本版本移除设备接入时的“允许目标”配置。转发目标统一在转发规则中指定，新增或修改目标无需重新配置出口服务。

## 更新内容

- 隧道和安全直连接入界面不再显示或要求填写“允许目标”，生成的安装命令不再包含 `-w`。
- 安装脚本和转发服务取消业务目标白名单限制，鉴权通过后按规则指定的目标地址转发。TLS、WS、WSS、HTTP 隧道支持 TCP/UDP，安全直连继续支持 TCP。
- 协议嗅探与禁用通过设备组高级设置配置，接入说明明确目标配置与协议策略的位置。
- 兼容旧安装命令中的 `-w` 和旧服务启动参数中的 TCP/UDP `-allow` 条目，这些条目不再限制业务目标。
- 反向出口身份授权和链式下一跳授权继续独立校验，不依赖业务目标白名单。
- 将 Go 和 Docker 构建环境升级到 Go 1.26.9，修复原有 Go 1.26.6 标准库中的 HTTP、TLS 等已知漏洞；Docker 构建镜像继续固定到校验过的 SHA256。

## 升级说明

本版本不新增数据库迁移。请更新面板及出口/安全直连目标设备的 Agent；仅更新面板不能取消旧版出口进程的目标限制。已保存的旧命令和服务配置可继续使用，重新执行新版接入命令会生成不含目标白名单的服务配置。

业务目标在转发规则中配置，协议嗅探与禁用在“设备组 → 高级设置”配置。详见 [Agent 接入说明](../../examples/agent-README.md)。

## 验证与产物

已通过 Go 全量测试、静态检查、转发相关并发检查、10 项隔离安装脚本测试、前端类型检查和生产构建，以及 Chromium、Firefox、WebKit 的界面回归和真实 Go/SQLite 联调。

真实本机 socket 测试覆盖无目标白名单的 TCP/UDP 转发、链式转发、连接复用、反向出口新增目标、凭据和证书拒绝、无效请求拒绝及安全直连的 TCP 限制。安装脚本测试使用隔离文件系统与模拟系统命令，不能替代公网部署验收。

发布附件包含 Linux amd64/arm64 二进制包、Docker amd64/arm64 安装包、安装管理脚本和 SHA256 校验文件。
