# v0.1.28

设备组高级设置改为按需选择参数并使用对应控件配置，同时保留 JSONC 兼容编辑器。

## 更新内容

- 高级参数通过下拉列表按需添加和移除，不再要求新组携带完整默认对象。
- 布尔值、数值、TLS 策略、反向隧道协议、应用协议、列表和设备组引用分别使用对应控件。
- 支持多行 Host、Path 列表，设备组引用从完整组列表加载，并保留未知字段编辑能力。
- JSONC 编辑器支持注释、格式化和显式应用，避免未应用的文本覆盖表单值。
- 补充零值、数值范围、TLS 对象、列表换行、设备组选择及移动端布局回归覆盖。
- 更新 API 契约、前端说明和嵌入式 UI 资源。

## 升级说明

本版本不新增数据库迁移。已有设备组高级设置继续按保存值读取；旧版顶层应用协议屏蔽会在首次打开高级设置时迁移到 `blocked_protocol`。安装脚本会按版本校验并保留升级前备份。

## 验证与产物

已通过 Go 平台测试、前端类型检查与构建、前端契约回归，以及 Chromium、Firefox、WebKit 的真实 Go/SQLite 后端联调。

发布包包括 Linux amd64/arm64 二进制、Docker amd64/arm64 安装包、安装脚本和 SHA256 校验文件。
