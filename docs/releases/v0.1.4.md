# v0.1.4

本版修复流量租约切换导致连接中断、用量上报阻塞配置同步的问题，统一探针页面的 1024 进位显示，并包含身份用户组、API 列表和隧道性能优化。

```sh
curl -fsSL https://github.com/kexue-aihao/Traffic-Forwarding-Panel/releases/download/v0.1.4/install-docker.sh -o install-docker.sh && sudo bash install-docker.sh
```

## 本版内容

- **流量连续性**：仅租约或授权有效期变化时保留 TCP 连接、UDP 会话与共享 TLS 路由，后续流量使用当前租约。TCP 在临时额度或待报队列不足时最多等待 30 秒；规则撤销、目标或限制变化仍会关闭旧连接。
- **同步隔离**：配置、用量和探针由独立任务同步，用量请求阻塞不再拖住撤销配置和探针上报。用量批次上限增至 500 条，额度不足时主动触发上报和续租。
- **探针单位**：实时及历史流量速率、内存、磁盘和交换空间统一按 1024 进位，1024 GB 显示为 1 TB；原始字节数和计费口径保持不变。
- **身份用户组**：支持创建、编辑、删除身份用户组和调整用户归属，设备组按身份用户组授权；权限检查、备份恢复、OpenAPI 和管理页面同步更新。
- **API 列表**：管理端与用户端提供接口检索和筛选，可查看参数、请求体、响应结构、认证要求及下载 OpenAPI 文档。
- **隧道优化**：合并帧写入、复用中继缓冲、减少 Mux 全局锁等待、复用 TLS 会话，并移除 WAL 固定批次等待；保留证书校验和先落盘后转发的计量约束。

## 升级

先按 [部署说明](https://github.com/kexue-aihao/Traffic-Forwarding-Panel/blob/v0.1.4/docs/docker-deployment.md) 备份，再更新面板和 Agent，保留现有数据、配置与管理员账号。发布附件包含 Linux amd64/arm64 二进制包、两个架构的 Docker 镜像包、安装脚本、Compose 文件及校验和。

面板启动会自动执行 cp schema v8 迁移：为已有用户建立独立的身份用户组并复制原有设备组授权，保留原权限范围。后续将多个用户合并到同一身份用户组会共享该组授权，调整前应核对设备组关联。需要回滚时，应配套恢复升级前的数据库备份。

连接连续性修复需要升级入口 Agent；首次替换或重启 Agent 本身仍会中断现有连接。租约续期不再因有效期变化主动重建连接，但短暂等待仍可能影响吞吐。详见 [流量连续性及验证边界](https://github.com/kexue-aihao/Traffic-Forwarding-Panel/blob/v0.1.4/docs/traffic-continuity.md)。

## 验证与限制

回归覆盖同一 TCP 连接跨越 16 MiB 租约传输 20 MiB、套餐周期切换、UDP 和共享 TLS 连续性、用量阻塞期间的撤销配置与探针，以及满队列恢复和取消。探针显示覆盖 1 TB 前后边界与桌面、移动端视口。

发布检查包含 Go race/vet、SQLite/PostgreSQL/MySQL 回归、OpenAPI 和前端产物一致性、三种浏览器的页面与真实后端测试、Caddy HTTPS 集成，以及两个架构的 Docker 安装测试。

商业租约仍最多为 5 分钟 / 16 MiB 加权预算。每块数据仍先写 WAL 并落盘后发送；发送失败保留既有的保守计量。UDP 在临时无额度时会丢弃当前数据报，长期控制面不可用、配额耗尽或存储失败仍会停止转发。本版不代表 Linux 跨机公网容量、真实支付或完整生产验收完成；Cyber 场景按既定指示跳过。
