# v0.1.22

面板上认机器的方式统一成**设备组**。网络诊断的节点下拉不再显示 `ip-172-31-3-144` 这种机器自报的主机名，而是显示设备组名；同一个组里不止一台时补上序号（`AWS日本-1`、`AWS日本-2`）。探针页的历史节点选择器用同一套规则（管理员那一栏仍是机器当前的公网 IPv4），取名逻辑收在一个共用函数里，两处不会再各长各的。

探针页的用户视角现在把「能不能对机器动手」也区分开了：WebSSH 与卸载设备在用户视角下一并收起。管理员自己切到用户视角预览时同样看不到 —— 否则预览出来的不是用户真正看到的那一屏。视角开关本身保留，不然切过去就切不回来。

转发规则支持分类：列表每行可勾选（表头全选本页），选中后批量归到一个分类下，也可以清空。分类存在 `cp_rules.category` 这一列，**不进发给 Agent 的配置**，所以归类既不 bump 规则版本也不 bump 节点期望版本 —— 归个类不该惊动节点，也不会和别处的编辑互相覆盖。列表支持按分类或「未分类」筛选，筛选值走 URL。新增 schema 版本 10；把列和版本记录删掉再让面板打开一次的实测通过：列补得回来，原有规则一条不少。

API 凭据可以限定设备组：签发时给 `group_ids`，这把钥匙就只覆盖这几个设备组，范围外的机器、规则、设备组、设备地址接口对它都不可见，指名范围外的组返回 403。**范围只能变窄** —— 列进来的组必须是账号自己也能看到的，否则签发直接 400；不填表示跟随账号的全部授权，升级上来的旧凭据行为不变。面板两处签发入口都能勾选。

设备地址接口（`/online/device/ip` 与 `/list`）的 `node_name` 改名为 **`group_name`**，值就是设备组名。字段名和内容对不上比改一次名字更贵；读 `device.node_name` 的脚本需要跟着改。同一个组里有多台机器时这几条记录的名字相同，靠 `ipv4`/`ipv6` 区分。

一键脚本的管理菜单在安装或升级失败时会打印退出码，不再静默回到菜单 —— 之前那种「点了没反应」让人以为升级流程在跑。浏览器测试与真实 Go/SQLite 后端集成测试在 chromium/firefox/webkit 三个引擎通过。
