# v0.1.26

修复套餐价格和流量配额的输入单位，价格按元填写，流量配额按 GB 填写，留空表示不限流量。

## 更新内容

- 套餐后台表单将价格标为元，服务端按人民币分精确保存，支持最多两位小数。
- 套餐流量配额按 GB 填写，支持小数并转换为字节保存；留空表示不限流量，套餐卡片和权益页面显示“不限流量”。
- 流量叠加包留空配额时，将当前权益切换为不限流量；有限叠加包仍按字节累加并检查溢出。
- 更新 API 合约、OpenAPI 文档、前端资源及套餐单位回归测试。

## 升级说明

本版沿用现有账务存储单位：价格为人民币整数分，配额为字节。已有套餐和权益数据不会改变；新的套餐创建或编辑可使用 `price_yuan` 与 `quota_gb` 字段，`quota_gb` 留空表示不限流量。

## 验证与产物

已通过 Go 全量测试、`go vet`、前端类型检查与构建、Chromium/Firefox/WebKit 回归、真实 Go/SQLite WebUI 回归，以及本地 8080 预览校验。
