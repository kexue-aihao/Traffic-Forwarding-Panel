# v0.1.7

探针页面改为紧凑设备列表，新增运行时长、机器累计上下行流量和 CPU/内存/磁盘进度条；保留分组过滤和历史趋势，流量继续按 1024 进位（1024 GB = 1 TB）。累计值来自系统网卡计数，重启或网卡重置可能归零，不代表转发计费流量。

管理员可在设备行点击 **WebSSH**，验证密码后通过 Agent 连接 Linux 交互终端，支持持续目录、Ctrl+C、交互程序和窗口缩放。无需开放 SSH 入站端口。会话最长 10 分钟，连接关闭或授权失效会结束会话。

新增 **卸载设备**：校验无关联转发规则且节点已确认停止后，由独立 systemd 服务在机器上卸载 Agent 和配套出口服务。成功回传后才从列表移除；网络失败会重试，历史流量与审计保留，用户证书不删除。等待设备领取时可取消，开始后不可撤销。远程卸载支持官方脚本的默认安装目录；自定义安装请在本机处理。

升级面板，复制完整一行：

```sh
curl -fsSL https://github.com/kexue-aihao/Traffic-Forwarding-Panel/raw/master/install.sh | bash
```

脚本自动备份并保留账号、数据库和配置。**旧设备还需重新执行设备组中的接入命令**，更新 Agent 和服务参数；已有身份保留，新的终端、卸载能力及累计流量字段才会生效。新安装默认启用终端与远程卸载。

验证覆盖 Go 测试、WebSocket 权限/取消、三浏览器交互与移动端、Linux PTY，以及真实 systemd 安装/卸载和回传失败重试；CI 同时验证 PostgreSQL、MySQL 和 Linux amd64/arm64 构建。
