# v0.1.31

同步流量混淆配置的 API 文档，并修复 Go CI 检查失败。

## 更新内容

- 包含 v0.1.30 之后新增的可选流量混淆配置与三种策略实现：随机填充、时序扰动和 TLS 流量模拟；相关参数说明见 Agent 文档。
- 修复混淆测试文件缺少末尾换行导致的 `gofmt` 检查失败。
- 重新生成 OpenAPI，补齐 `ObfuscationConfig` 和隧道 `obfuscation` 字段，修复生成文件一致性检查。
- CI 格式检查失败时输出文件名和格式差异，便于定位问题。

## 升级说明

本版本不新增数据库迁移。混淆默认关闭；使用新增配置时需同步升级相关 Agent。安装脚本按版本校验并保留升级前备份。

## 验证与产物

发布检查包括 Go 格式、OpenAPI 生成一致性、静态检查、竞态检测测试、PostgreSQL/MySQL 回归、前端检查，以及 Docker 安装与 HTTPS 反代验证。

发布包包含 Linux amd64/arm64 二进制、Docker amd64/arm64 安装包、安装脚本和 SHA256 校验文件。
