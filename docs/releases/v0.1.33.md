# v0.1.33

本版本集中修复部署供应链、支付通道配置生命周期和密码重置接口的安全与可靠性问题，并同步更新 CI 依赖检查。

## 更新内容

- 安装管理器固定到源码提交，下载强制使用 HTTPS；在线和离线安装器执行前校验发布包中的 SHA256 清单。Dockerfile、Caddy 和 GitHub Actions 使用固定 digest/commit，CI 增加依赖漏洞检查与可变 Action 引用拦截。
- 支付设置删除通道或轮换网关、商户号、密钥、币种、签名算法和 EPay 模式时，会检查待处理订单；存在待回调或待对账订单则拒绝修改，避免历史订单失去验签或查单能力。修复旧版 EPay fallback 在同进程动态删除后重新生效的问题。
- 密码重置请求和确认按客户端 IP 分别限制为每分钟五次，超限返回 429；账号级冷却和验证码尝试次数保持不变。
- 补充数据库结果集错误检查，并保留上一版本的迁移、并发、分页、金额和传输层修复。

## 升级说明

本版本不新增数据库迁移。已有待处理支付订单在通道关键配置变更前需要先完成回调或对账；手续费、汇率和回调展示地址仍可调整。更新面板和 Agent 时请使用同一版本的发布包。

## 验证与产物

已通过 Go 全量测试、竞态测试、`go vet`、OpenAPI 一致性检查、前端依赖审计、类型检查和构建。发布包包含 Linux amd64/arm64 二进制、Docker amd64/arm64 安装包、安装脚本和 SHA256 校验文件。
