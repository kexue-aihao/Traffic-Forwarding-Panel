# v0.1.40

设备组高级设置现在可以在明确可验证条件下嗅探并禁用 Shadowsocks、Trojan、VMess 和 SOCKS5，覆盖直连入口和入口→出口。控制面校验节点能力与本地凭据准备状态，入口和托管出口各自检查实际业务流，并显示观测位置、协议变体、证据及拒绝原因。

## 更新内容

- Shadowsocks AEAD 2017/2022 TCP/UDP 认证检测：AES128/256-GCM、ChaCha20-Poly1305，以及 SS2022 AES SIP023 多用户密钥链；VMess AEAD 验证完整认证请求，覆盖其 TCP 内 UDP/mux，body none/zero 不跳过认证。
- SOCKS4/4a、SOCKS5 完整结构检查，修正普通 UDP 报文首字节碰撞误判；SOCKS5 UDP 支持显式结构模式与实际 TCP UDP ASSOCIATE 关联，逐报核对来源、目标、规则和本地代次，控制关闭及凭据轮换撤销关联。
- Trojan 在受控业务 TLS 终止后的可见明文位置核对已知认证凭据；可重建并验证上游 TLS。受控 WebSocket 对解掩码检查视图进行检测，允许流保留原始帧；分片、显式早数据和截断帧均有有界处理。
- 出口依据真实流再次认证，v4 分阶段检查在连接源站前裁决；普通旧隧道保留入口检查。链式/反向/UDP-over-TCP/QUIC 解封装位置使用统一检测器和独立诊断。
- 保持组策略 v2，新增 inspection v1、严格/观察模式、独立未知业务策略与本地标签；密码、密钥、UUID、认证摘要和证书私钥不进入面板配置或诊断。仅观察候选缺少前提时显示不可用，不阻止无关规则配置。
- Agent 新增 `-inspection-profiles`、`-business-profiles`；Debian/Ubuntu、Red Hat、Arch 系接入脚本通过 `-I` / `-B` 部署本地私有 JSON。新生产依赖的原始版权声明随文档与 Docker 镜像打包。

## 升级和配置

升级面板及承担检测的入口、出口 Agent，分别部署本地检测凭据文件；业务 TLS 适配还需业务证书/CA 与精确监听、目标许可。等待节点上报准备状态，在管理员设备组高级设置显式启用相应协议与 inspection v1。出口启用新检测必须使用支持对应能力的托管服务，跨 hop 业务适配还要求授权 grant 与 v4 能力。

Shadowsocks/VMess 需要支持的 cipher/版本及已知本地凭据；Trojan 需要受控业务 TLS 终止。无法准确识别任意未知密钥的第三方加密流量；未知默认允许，`unknown=deny` 是独立访问策略。SOCKS5 UDP 关联模式要求同 Agent、同账号、固定可见 TCP/UDP 控制关系和精确数字监听端点，服务实际成功 BND 必须等于入口公开 UDP 端点；出口不接受入口自报关联作为独立证据。VMess/Trojan 的 UDP 命令位于 TCP 协议流内部。

存量组策略 v2 保持兼容，不自动启用新增检测。升级前备份数据库、Agent 状态与本地配置；从 v0.1.37 或更早版本升级仍需遵守 v0.1.38 WAL 2 迁移与回滚限制。部署示例和支持范围见 [协议检测交付说明](https://github.com/kexue-aihao/Traffic-Forwarding-Panel/blob/v0.1.40/docs/protocol-sniffing-implementation.md)。

## 验证与边界

本地全仓竞态测试、Go vet、前端类型检查/构建、Chromium/Firefox/WebKit 模拟与真实面板回归、19 项安装器模拟检查、Linux amd64/arm64 编译全部通过。固定官方 Xray v26.3.27 的 16 个真实客户端场景及独立 Shadowsocks/V2Fly 编码验证关闭→阻断→恢复；出口短前缀测试同时核对零业务字节泄漏，v4 核对没有源站连接。UDP 六种 cipher、独立出口/链式/反向/QUIC、SOCKS 关联来源隔离及撤销均检查真实源站与拒绝证据。

发布流程在 Linux 执行全仓 race、独立 Xray、SQLite/PostgreSQL/MySQL、真实 systemd、HTTPS 与双架构 Docker 安装验证；最终结果见本版本 GitHub Actions。功能回归不代表 Linux 跨机吞吐/PPS/P99、无策略 5% 性能预算或 24 小时稳定性达标；这些指标仍须按 [UDP 验收手册](https://github.com/kexue-aihao/Traffic-Forwarding-Panel/blob/v0.1.40/docs/udp-performance-lab.md) 实测。

透传业务 TLS、未知密钥、gRPC/HTTP2 内层及未支持插件不能宣称覆盖；VMess legacy 仅观察诊断，SS legacy 不提供认证禁用。WebSocket 为完成外层握手可能已向源站发送合法 HTTP 请求；已发送并计量的隧道字节不会自动退款，逐 hop 拒绝计数不能相加作为用户连接数。

附件包含 Linux amd64/arm64 二进制包（panel、agent、udpbench）、Docker amd64/arm64 安装包、安装管理器、Compose 和两份 SHA256 清单。
