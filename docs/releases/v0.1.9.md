# v0.1.9

探针设备列表现在分别显示 IPv4 和 IPv6 地址，并为两个地址族分别展示 IP 归属图标。双栈设备不会再把 IPv4 的归属地错误复用到 IPv6；归属地查询未完成时仍保留明确的未知状态。

控制面新增 `ipv4_location` 与 `ipv6_location` 字段，同时保留旧的 `location` 字段兼容已有客户端。管理员可看到 Agent 已上报的公网地址，普通账号继续只看到位置图标，不会获得原始公网地址。

本版同步更新 OpenAPI 文档、前端嵌入产物和 Docker 安装脚本。验证覆盖 Go 全量测试、前端类型检查、生产构建，以及 Chromium 探针双栈展示场景。
