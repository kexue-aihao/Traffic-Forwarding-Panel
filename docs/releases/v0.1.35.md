# v0.1.35

本版本支持直接用设备公网 IP 申请受信任的 TLS 证书，无需准备域名，并自动续签和加载新证书。

## 更新内容

- 安全直连和隧道接入的 `public-ip` 模式自动探测公网 IPv4；IPv4 不可用时尝试 IPv6，并调整默认监听地址以接受 IPv6 连接。
- 通过 Certbot 向 Let's Encrypt 申请 `shortlived` IP 证书，有效期 160 小时。优先使用支持 IP 证书的已安装 Certbot，否则创建独立 Python 环境安装兼容版本。
- 安装 `tfp-cert-renew.timer`，每 6 小时检查续签。新连接在握手时加载轮换后的证书，已有连接保持运行；证书和私钥尚未同时更新时保留上一对。
- 公网 IP 证书模式隐藏目标设备服务名、证书路径和私钥路径，生成的接入命令不再要求 `-S`。
- 按 IP SAN 校验 IP 证书，保持客户端证书验证；卸载设备或切换证书模式时清理受管续签任务。

## 升级说明

本版本不新增数据库迁移。请同时更新面板和目标设备 Agent，重新执行 `public-ip` 模式的接入命令以安装证书及续签任务。已有 `provided` 和按域名申请的 `auto` 模式继续可用。

首次申请和后续续签都需要公网 TCP/80 可达且端口未被占用，包括云安全组、系统防火墙和 NAT 转发。自动安装 Certbot 需要 Python 3.10 或更高版本，以及 PyPI、ACME 和 ipify 网络连接。使用脚本输出的 IP 端点，TLS 服务器名称可留空；公网 IP 改变后需重新执行接入命令并更新端点。详见 [Agent 接入说明](../../examples/agent-README.md#公网-ip-证书无需域名)。

## 验证与产物

验证覆盖安装及续签命令、IPv6 回退、无效地址、申请失败、旧版 Certbot 替换、任务清理、严格 IP 校验、实际 TLS 证书轮换和安全直连传输，并完成前端类型检查、生产构建与 Chromium/Firefox/WebKit 回归。

安装流程测试使用隔离文件系统及模拟系统命令、ACME 响应；TLS 测试使用测试 CA。以上不代表已在真实公网机器完成 CA 签发或跨日续签验收。

发布附件包含 Linux amd64/arm64 二进制包、Docker amd64/arm64 安装包、安装管理脚本和 SHA256 校验文件。
