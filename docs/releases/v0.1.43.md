# v0.1.43

修复 WebSSH 复制粘贴，在探针页面增加手动升级 Agent 和悬停速率查看机器 TCP/UDP 数量。

## 更新内容

- WebSSH 增加「复制选中」「粘贴」按钮，支持复制粘贴快捷键和原生剪贴板事件。浏览器拒绝 Clipboard API 或 HTTP 页面无法读取剪贴板时，提供复制回退和手动粘贴输入框；保留长 Unicode 输入分块与终端中断行为。
- 探针页在 WebSSH 与「卸载设备」之间增加「升级 Agent」。自动读取面板签名产物，输入管理员密码即可手动升级并查看进度；关闭自动升级后仍可使用。已有活动任务阻止重复提交，请求结果不确定时保留幂等键，失败或回滚后可重试，禁止降级。
- 未初始化升级能力、公钥不匹配、产物或 HTTPS 地址不可用时显示原因与处理入口；旧节点可从升级弹窗直接打开 WebSSH，完成首次接入初始化。
- 悬停探针顶部或列表中的实时速率，可查看整台机器的 TCP 连接数、UDP 套接字数，支持键盘聚焦、手机点击和 Esc 关闭。提示随实时推送更新，并显示采样时间及在线、陈旧、离线状态；未上报或采集不可用时显示未知，零值保留为零。
- 连接数包含 Agent 所在网络命名空间的 IPv4/IPv6。TCP 统计 ESTABLISHED/CLOSE_WAIT，UDP 统计本地套接字；Linux 直接读取内核汇总计数，避免枚举全部进程和连接。
- 转发 TCP 继续沿用机器的内核拥塞算法，增加系统设置继承回归与 BBR 排查说明；没有新增强制切换算法或公网提速承诺。

## 升级注意事项

需要同时更新面板和 Agent，才能显示新的连接数；旧 Agent 在新面板上显示未知。完整面板安装包和 Docker 镜像均携带两种架构的 Agent 及发布清单。

**未配置升级公钥和监督进程的旧节点（例如原有 v0.1.36 安装）仍需重跑一次设备组的完整接入命令，之后才能自动跟随面板升级。** 保留原数据库、Agent 状态目录、证书和部署参数；跨 v0.1.38 的旧状态迁移前先停止服务并备份。升级会重启 Agent，现有转发连接会短暂中断，健康检查失败时恢复旧程序。

本版不新增数据库迁移或 Agent 账本格式，不新增连接数历史聚合指标。详细说明见 [Agent 自动升级](https://github.com/kexue-aihao/Traffic-Forwarding-Panel/blob/v0.1.43/docs/agent-auto-upgrade.md)、[探针接口契约](https://github.com/kexue-aihao/Traffic-Forwarding-Panel/blob/v0.1.43/docs/api-contract.md#实时探针连接数) 和 [TCP/BBR 排查](https://github.com/kexue-aihao/Traffic-Forwarding-Panel/blob/v0.1.43/docs/tcp-congestion-control.md)。

## 验证与附件

回归覆盖剪贴板缺失与拒绝、升级权限与签名产物选择、任务生命周期及幂等重试、连接数双栈合计、零值与未知、旧 Agent 兼容，以及三浏览器的实时推送、键盘和窄屏交互。Linux 全仓竞态、三库、systemd、HTTPS 与双架构 Docker 安装结果见本版本 GitHub Actions；发布不代表已部署到用户服务器或完成公网性能验收。

附件包含 Linux amd64/arm64 二进制包（panel、agent、udpbench、双架构 Agent 与发布清单）、Docker amd64/arm64 安装包、安装管理器、Compose 和两份 SHA256 清单。
