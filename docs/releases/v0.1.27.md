# v0.1.27

套餐限制收敛为规则总数，并增加管理员对指定账号余额和规则额度的调整能力。

## 更新内容

- 套餐 `limits` 只保留 `max_rules`；连接数、活跃 IP 数和带宽不再作为套餐限制或账号套餐额度。
- 管理员可在用户管理的“余额与规则”中查看账号余额、规则数和套餐上限。
- 支持按原因增加或扣减指定账号余额，使用幂等键和账本事务避免重复入账。
- 支持为指定账号设置规则总数覆盖值；`0` 表示不限，留空表示跟随已购买套餐。
- 余额调整在网络结果不确定时可安全重试，前端会保存并复用原调整意图和幂等键。
- commerce schema 升级至版本 9，新增账号规则覆盖和管理员调整记录表；旧数据自动迁移。
- 更新 OpenAPI、前端嵌入资源和真实后端浏览器回归测试。

## 升级说明

启动时自动执行 commerce schema v9 迁移。已有套餐和权益中的旧连接/IP/带宽限制字段会被忽略，商业套餐只按规则总数执行；Agent 运行时安全能力字段仍保留以兼容已有配置。升级前应按部署说明备份数据库，旧程序不能直接读取升级后的账号调整表。

## 验证与产物

已通过 Go 测试、前端类型检查与构建，以及 Chromium、Firefox、WebKit 的前端和真实 Go/SQLite 后端回归；真实联调覆盖服务端已入账但浏览器丢失响应后的余额重试，确认不会重复入账。

发布包包括 Linux amd64/arm64 二进制、Docker amd64/arm64 安装包、安装脚本和 SHA256 校验文件。
