# v0.1.3

本版补齐高级设备组、启动配置和 Caddy 自动 HTTPS 部署能力，并扩展资源限制、转发策略和浏览器端管理界面。

```sh
curl -fsSL https://github.com/kexue-aihao/Traffic-Forwarding-Panel/releases/download/v0.1.3/install-docker.sh -o install-docker.sh && sudo bash install-docker.sh
```

## 本版内容

- **设备组高级配置**：支持 monitor、entry、exit、chain_exit 组类型、入口直连策略、禁用网络/承载、链式出口顺序和兼容参考配置字段；高级设置在独立面板中编辑。
- **资源与转发限制**：补齐组级规则上限、共享连接/IP/速率限制、请求大小与速率限制，以及跨入口、出口和链路的策略校验。
- **启动配置**：面板支持 YAML 配置文件、`-check-config` 校验和 `-export-html` 导出前端；示例配置位于 `examples/panel.config.yaml`。
- **Caddy 部署**：新增 Caddy Compose 配置、自动 HTTPS 部署文档和 HTTPS 集成测试；现有 Docker/1Panel 部署方式继续可用。
- **API 与前端同步**：OpenAPI schema、资源/探针/出口页面和高级设备组组件同步本版接口；新增客户端 IP 识别、连接选项及相关回归测试。

## 升级

已安装的旧版按 [部署说明](https://github.com/kexue-aihao/Traffic-Forwarding-Panel/blob/v0.1.3/docs/docker-deployment.md) 备份后导入新镜像、更新 Compose；保留 `data/`、配置和管理员账号，不重新初始化。数据库迁移随启动自动执行。使用 Caddy 配置参数时请从本版源码或发布包构建，旧版二进制不包含这些启动选项。

## 已知限制

- 租约续期仍可能重建监听并关闭旧连接；连接连续性、参考容量/性能、Linux 跨机/公网和真实支付验收继续等待后续安排。
- Caddy 自动 HTTPS 需要公网域名和可用的 80/443 端口；内网或已有反向代理环境请继续使用对应部署文档。
- 本版发布不代表完整 P0–P6 生产验收已完成，Cyber 场景按既定指示跳过。

验证：Go 生成检查、`go test ./...`、`go vet ./...`、前端 typecheck/build，以及现有浏览器和 Caddy 集成测试均通过；OpenAPI 产物与生成器保持同步。
