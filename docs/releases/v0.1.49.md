# v0.1.49

本版把规则导入、导出完整移到「转发规则」页，便于在管理规则时直接操作。

## 规则导入与导出

- 「转发规则」页的「新增」按钮旁新增「导入」「导出」按钮，沿用原有按钮、表单和弹窗样式。用户端与管理端均可直接打开弹窗。
- 「运营与任务」页移除规则导入、导出区域。预览、确认导入、任务列表、刷新、取消、查看结果和下载均在对应弹窗内完成。
- 保留面板规则 JSON 和端口转发 JSON Lines。每行一个包含 `dest`、`listen_port`、`name`、`proxy_protocol` 的 JSON 对象继续支持；入口节点与设备组选取、按节点/协议/端口更新及转换规则沿用 v0.1.48。
- 关闭导入弹窗后刷新规则列表，关闭弹窗时恢复到触发按钮的键盘焦点。

## 验证

前端类型检查、构建，以及 Chromium、Firefox、WebKit 的模拟 API 与真实 Go/SQLite 后端回归通过。回归覆盖入口位置和样式、运营页移除、弹窗焦点恢复、JSON Lines 单/多目标导入、预览回滚、按端口更新及两种格式下载。最终提交的 Linux、三数据库、HTTPS、systemd 与双架构 Docker 验证见本版 GitHub Actions。

## 升级

更新面板后刷新浏览器页面，即可在「转发规则」页看到新入口。本版没有数据库迁移或 WAL 格式变化，升级时保留数据库、证书和部署参数。附件包含 Linux amd64/arm64 二进制包、双架构 Docker 安装包、安装管理器、Compose 和两份 SHA256 清单。
