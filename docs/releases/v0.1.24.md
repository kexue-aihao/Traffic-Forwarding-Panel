# v0.1.24

修复注册入口不易找到，以及修改注册策略后退出登录仍沿用旧配置的问题。

## 更新内容

- 开放注册或邀请码注册时，管理员登录页增加“注册账号”入口，跳转到用户注册表单。
- 用户入口支持 /?register=1 直接打开注册表单；关闭注册时不显示注册控件，也不会通过该链接开启注册。
- 退出登录后重新读取已保存的站点配置，注册策略与验证码设置立即跟随服务端配置；同时清空登录和注册表单状态。
- 注册密码字段使用 new-password 自动填充提示。
- 补充真实后端浏览器回归：开放注册、邀请码注册、关闭注册、后台退出后入口刷新，以及从后台入口完成普通用户注册。

## 升级说明

本版不增加数据库迁移，不改变站点已保存的注册策略。升级后仍需在“站点设置 → 注册与登录”选择策略，并点击“保存站点设置”。仅修改下拉选项但未保存，不会开放注册。

本地预览的注册策略已单独保存为开放注册；该预览数据库与账号数据不会打入发布包。

## 验证与产物

注册修复已通过 Chromium、Firefox、WebKit 的真实 Go / SQLite 后端测试。发布还需通过完整 GitHub CI、三数据库回归、race、双架构编译及 Docker 安装检查。

提供 Linux amd64 / arm64、Docker amd64 / arm64 安装包，以及安装脚本和 SHA256 校验文件。
