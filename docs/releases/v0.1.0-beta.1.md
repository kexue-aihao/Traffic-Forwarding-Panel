# v0.1.0-beta.1

首个公开预发布版，提供 Go 面板、独立 Agent 和内嵌 Vue 管理员/用户界面。目标部署平台为 Linux amd64/arm64，支持 SQLite、PostgreSQL、MySQL，当前使用单控制面实例。

## 本版功能

- 四种加密承载（TLS/WS/WSS/HTTP）、TCP/UDP 转发、最多三出口链式、反向隧道、Mux、TLS SNI 共享端口和 TCP 多后端故障转移。
- 受管出口、按权重自动选路、入口与出口组精确倍率计费；Proxy Protocol v1/v2 收发与可信来源限制。
- 钱包、版本化套餐、叠加包、自动续费、兑换码、邀请返佣；充值来源分摊、购买部分退款、配额扣回与佣金同步回冲。
- EPay、EPUSDT、BEpusdt、TokenPay、Cryptomus 协议适配，以及支持渠道的后台查单和人工外部退款登记。Cyber 按要求跳过。
- 规则导入预览、按端口更新、异步导入/导出；Agent 执行的有限网络诊断；节点终端和签名升级能力。
- 实时与历史探针、持久状态告警、Webhook/飞书/Discord 通知、站点品牌与公告、注册开关/邀请注册、验证码和充值限制。
- 104 个操作的 OpenAPI 3.1 契约、数据库快照备份恢复、所有者范围 API Token、节点能力及权限检查。

## 下载与启动

选择对应架构的 `traffic-forwarding-panel_0.1.0-beta.1_linux_amd64.tar.gz` 或 `linux_arm64.tar.gz`，同时下载 `SHA256SUMS`。在下载目录执行：

```sh
sha256sum --ignore-missing -c SHA256SUMS
tar -xzf traffic-forwarding-panel_0.1.0-beta.1_linux_amd64.tar.gz
cd traffic-forwarding-panel_0.1.0-beta.1_linux_amd64
./panel -version
./agent -version
./panel -init-admin admin
./panel -addr 127.0.0.1:8080
```

初始化命令从标准输入读取密码（12–72 字节），完成后退出。ARM64 请替换归档名和目录名。访问 `/admin` 管理入口，普通用户入口为 `/`。安装包内包含 README、Agent/支付配置示例、完整文档、OpenAPI 和记录提交号的 `BUILDINFO.json`。

已有开发版数据应先停止面板并备份数据库、支付配置、证书和 Agent 状态，再同时更新面板及 Agent。本版启动迁移至 cp v4、commerce v6；不承诺向旧程序降级兼容。旧购买没有资金来源记录时，不允许自动追溯退款。

本次归档用于手动安装；SHA256SUMS 是完整性校验，不是 Agent 在线升级所需的 Ed25519 签名清单。

## 验证和边界

本机已运行 Go 全量 race/vet、PostgreSQL 回归、MySQL 新功能顺序专项，以及前端类型检查/构建和 Chromium、Firefox、WebKit 的 fixture/真实 Go+SQLite 流程。Windows 上 MySQL 并行全量测试曾因 DDL 等待超时，顺序专项重跑通过；具体测试证据见实施状态。发布安装包由 Windows 交叉编译，并检查 ELF 架构与提交元数据。

以下三项按用户指示留待后续：租约续期时的连接连续性、容量/性能工作、Linux 跨机/公网/真实商户验收。因此本版标记为 prerelease，不代表生产验收完成。当前续租可能重建监听并关闭连接；连接/IP/带宽限制按单入口节点合计。支付退款仍需操作员在商户侧执行并录入凭证，未实现自动商户退款、拒付或欠款。

## 构建发布包

在干净且已提交的源码目录，安装 Go 1.26 和 Python 3.10+，执行 `python3 scripts/release.py`（Windows 使用 `py -3 scripts/release.py`）。脚本读取 `VERSION`，注入程序版本，生成两个架构的安装包与 `SHA256SUMS`，默认输出到 `.local/releases/v0.1.0-beta.1`。前端产物已提交；修改前端后须先重新构建并提交。
