# v0.1.38

本版本优化直连 UDP，新增入口到普通单出口的 QUIC DATAGRAM 通道，并补齐 Debian/Ubuntu、Red Hat 与 Arch 系列的 Agent 接入脚本兼容处理。规则表单继续由 TCP/UDP 和出口选择确定路径；协议嗅探与禁用仍在管理员设备组高级设置配置。

## 更新内容

- 直连 UDP 使用会话哈希 worker、异步目标建连、复用缓冲和有界队列；Linux 增加批量收发、socket 缓冲与内核溢出诊断。
- 普通单出口可配置独立 UDP 端点，入口到出口通过 TLS 1.3 QUIC DATAGRAM 传输业务报文；可靠 stream 承载认证与会话控制。支持连接复用、空报文和有界分片重组。`udp_over_tcp` 由管理员显式选择，UDP 网络故障不隐式降级。
- 提前持久化有限额度窗口，逐包扣内存额度，后台结算；当前与备用商业租约连续补充。正常流量与崩溃恢复结算分别审计，恢复责任有明确上限，仍绑定原租约和权益周期。
- 管理员新增用量审计页面；出口管理、接入命令与安装器增加 UDP 配置和 `-D` 参数。数据库 schema 12 预留出口物理 TCP/UDP 端口并保留旧共享端口归属。
- 接入脚本识别 Debian/Ubuntu、RHEL/Rocky/AlmaLinux/CentOS/Fedora、Arch/Manjaro；按需使用 apt、dnf/yum、pacman 安装依赖，处理较旧 Python、SELinux 文件标签及私有 CA 下载验证。
- Linux 二进制包新增 `udpbench`，提供独立 B0/B1/B2 基线、上传/下载/回显、序号/CRC 校验和 JSON 报告。

## 升级与回滚

需更新面板及入口、出口 Agent 才能使用新 UDP 通道。普通出口配置 `-udp-listen`（安装器 `-D`）并开通相应 UDP 端口；面板出口管理填写匹配的 UDP 端点、证书名与凭据。旧节点按能力接收兼容配置；链式和反向出口继续使用原兼容路径。

**本版有数据库迁移和 Agent 持久状态升级。** Agent 使用 WAL 2 / `TFPWAL02`，可迁移旧状态；旧二进制不能直接读取新状态。升级前在 Agent 停止时备份快照、WAL 及相邻恢复文件，并备份面板数据库。新版本消费额度后不能直接恢复旧 Agent 备份，否则可能重复消费预算。

正常计量记录发送前已授权的业务字节，不证明对端收到。崩溃恢复对未确认窗口责任保守结算，单次额外原始字节上限为单规则 1 MiB、同账号单 Agent 8 MiB，仍受实际窗口和租约余额约束；重复异常退出分别累计恢复责任。详情与受控降级步骤见 [实现与升级说明](../udp-performance-implementation.md)。

接入要求 root、Bash、运行中的 systemd；首次下载脚本需 curl 与 CA 信任库。普通 Agent 和自备证书出口不需要 Python；自动 IP 证书需要 Python ≥3.10、venv/pip 和可达的公网 TCP/80。各发行版版本与软件源边界见 [Linux 兼容性说明](../agent-linux-compatibility.md)。

## 验证与边界

本地 Go 全量测试、vet、相关 race 检查、前端类型检查/构建、Chromium/Firefox/WebKit 回归、Linux amd64/arm64 交叉编译和 25 项接入/证书隔离回归均通过。发布流程另执行 Linux 全量 race、SQLite/PostgreSQL/MySQL 回归、真实 systemd 接入/卸载、浏览器与 HTTPS 联调，以及双架构 Docker 安装验证；最终结果见本版本 GitHub Actions 记录。

**尚无 Linux 跨机吞吐、PPS、P99 延迟及 24 小时稳定性达标证据。** Windows 回环与功能测试不代表达到“原生 UDP 性能”指标，也不代表所有发行版已完成实机安装。受控 MTU/丢包/NAT、Red Hat SELinux、Arch 实机与公网 ACME 仍需隔离验收。测量方法见 [性能验收手册](../udp-performance-lab.md)。

发布附件包含 Linux amd64/arm64 二进制包（panel、agent、udpbench）、Docker amd64/arm64 安装包、安装管理脚本和 SHA256 校验文件。版本发布不执行用户服务器部署。
