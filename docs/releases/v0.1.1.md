# v0.1.1

修复一键部署必须输入域名的问题。现在执行命令即可下载镜像、配置并启动容器，全程无需域名或交互输入：

```sh
curl -fsSL https://github.com/kexue-aihao/Traffic-Forwarding-Panel/releases/download/v0.1.1/install-docker.sh -o install-docker.sh && sudo bash install-docker.sh
```

- 自动初始化 `admin`，生成随机密码并在安装完成时显示；已有安装保留账号及数据。
- 默认服务地址 `http://127.0.0.1:18080`，数据目录 `/opt/traffic-forwarding-panel/data`，域名与 HTTPS 由 1Panel 配置。
- 无需 `TFP_ORIGIN`，受控代理模式通过保留的 Host 和 `X-Forwarded-Proto` 识别访问地址；修复 HTTPS 反代下的登录、商业操作和 WebSocket 来源校验，Secure Cookie 随 HTTPS 设置。
- 保留跨站请求拦截；默认二进制运行不信任代理协议头，显式指定 Origin 时继续固定域名。
- 提供 amd64/arm64 Docker 镜像包、Linux 二进制、Compose 和 SHA256 清单。双架构安装测试采用空标准输入，并覆盖 HTTPS 登录、商业写操作、SSE、重启后数据保留和重复安装。

在 1Panel 新建反向代理，代理地址填 `http://127.0.0.1:18080`，保留 Host、设置 `X-Forwarded-Proto $scheme`，启用 HTTPS/WebSocket、关闭代理缓存。管理员入口为站点 `/admin`。

v0.1.0 在空域名提示处退出尚未写入安装数据，直接执行本版命令即可。已成功安装的旧版按 [部署说明](https://github.com/kexue-aihao/Traffic-Forwarding-Panel/blob/v0.1.1/docs/docker-deployment.md) 备份后更新镜像及 Compose，保留数据与管理员，不重新初始化。支付渠道的回调地址可单独配置，容器安装不依赖它。

当前租约续期可能关闭旧连接；连接连续性、容量/性能工作、跨机/公网/真实支付验收继续按原指示等待后续安排。
