# v0.1.37

新增和编辑转发规则时不再选择“转发方式”。无出口的新规则直接转发；选择出口或链式出口时，实际承载由出口配置自动决定。协议嗅探与禁用在管理员后台“设备组 → 高级设置”配置。

## 更新内容

- 移除规则弹窗中的转发方式及手工隧道配置，包括 TLS 校验名、隧道端点与凭据、混淆策略、Mux、反向出口和后续出口编辑。
- 已配置出口的规则取消出口选择后恢复直接转发，避免继续提交原出口的隧道承载而导致保存失败。
- 旧手工隧道规则编辑名称、目标等字段时保留原承载、链路和凭据；API 继续兼容已有规则及客户端。
- 探针卡片使用设备组名称显示，优先显示当前筛选组；缺少组信息时回退到节点名称，节点短 ID 继续用于区分设备。

## 升级说明

本版本不新增数据库迁移。更新面板即可应用界面调整；本次修改不需要更新 Agent。旧手工隧道的承载参数继续保存，需要修改这些参数时可通过兼容 API 操作。

## 验证与产物

Go 全量测试、静态检查、前端类型检查、生产构建，以及 Chromium、Firefox、WebKit 的界面回归和真实 Go/SQLite 联调均通过。联调覆盖直连规则创建、出口自动承载、取消出口后直连，以及旧三跳隧道编辑后的配置保留。

发布附件包含 Linux amd64/arm64 二进制包、Docker amd64/arm64 安装包、安装管理脚本和 SHA256 校验文件。Docker 安装与 HTTPS 反向代理验证由发布工作流执行。
