# v0.1.6

设备组列表新增管理员「删除」按钮和确认弹窗。删除后解除该组的设备归属与身份组授权、清理闲置出口，原接入命令失效；设备本身、其他组归属、租约、历史流量和账单保留。

正在被转发规则（含停用规则）、链式出口或高级设置引用的设备组会拒绝删除，并提示具体原因。已删除规则须等节点确认停止、释放端口后才能删除设备组；节点确认后清理规则内部记录，延迟上报的流量仍可按原租约入账。删除操作校验版本并写入审计，普通用户和 API Token 不具备此权限。

升级命令：

```sh
curl -fsSL https://github.com/kexue-aihao/Traffic-Forwarding-Panel/releases/download/v0.1.6/install-docker.sh -o install-docker.sh && sudo bash install-docker.sh
```

沿用 v0.1.5 的备份升级流程，保留已有账号、数据库和配置。本次设备组删除功能只需升级面板。

验证涵盖删除与取消、移动端确认弹窗、引用冲突、权限与版本检查、并发创建引用、设备多组归属保留、接入凭据失效、节点停止确认，以及删除后的流量重放去重、延迟入账和租约回收。
