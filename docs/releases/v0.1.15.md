# v0.1.15

Agent 探测公网地址时，IPv6 问的是 `api.ipify.org`，而这个域名只有 A 记录、没有 AAAA，`curl -6` 每次都停在 DNS 解析失败上 —— IPv6 这一路自加入以来从未上报成功过。现在按地址族选域名：IPv4 问 `api.ipify.org`，IPv6 问 `api6.ipify.org`。这条修复在 Agent 里，需要重新执行接入命令更新 Agent 才会生效；机器本身没有 IPv6 出口时仍只上报 IPv4，这是预期行为。

WebSSH 不再要求管理员密码，打开即可连接。做法是给运维授权加范围：不带密码换来的授权只够开终端，卸载和升级仍然要密码换来的敏感授权，二次验证没有被一并取消。数据库相应增加一列（schema v9），旧授权按敏感处理，行为不变。

探针页面新增「视角」切换（仅管理员可见）：切到用户视角后机器地址显示为「已隐藏」、位置图标照旧，用来核对普通账号实际看到的内容。IPv4/IPv6 前的国旗图标放大到与状态标记同高。功能范围与 v0.1.14 相同，chromium/firefox/webkit 浏览器测试与真实 Go/SQLite 后端集成测试均通过。
