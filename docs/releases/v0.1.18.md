# v0.1.18

探针页面几处可用性修正。选中文字的高亮原来只有一成透明度，在深色底上几乎看不见 —— 而这一页的地址正是要被选中复制的东西；现在改成六成品牌色的实心块。历史趋势的波形图改为每 5 分钟一个点：一分钟一个点时 24 小时窗口有 1440 个点，图上挤成一团噪声；组内只要缺一次采样，这个点就整点留空，断线仍然是图上「这里没测到」的唯一信号。历史趋势的节点下拉改为显示该机器的公网 IPv4，同一设备组里有多台时可以分辨，取不到地址时退回机器名。

WebSSH 支持选中文本即复制。Agent 接入脚本在安装完成后会打印本机的相关路径（程序、节点身份、环境文件、服务单元、出口单元、根证书、卸载脚本），并把卸载脚本一并落到 /etc/tfp-agent/；面板新增 GET /download/agent-uninstall.sh，面板不可达或 Agent 起不来时用它拆机（默认保留节点身份，-p 连身份一起删）。卸载对话框里也给出了这条命令。

功能范围与 v0.1.17 相同，chromium/firefox/webkit 浏览器测试与真实 Go/SQLite 后端集成测试均通过。
