# v0.1.30

修复 PostgreSQL 检查中 Telegram 密码重置测试的 SQL 占位符错误。

## 更新内容

- 测试数据写入统一使用数据库驱动的占位符转换，PostgreSQL 不再因 `?` 占位符报语法错误。
- 运行时功能没有变化；站点 Logo、Telegram 查询和忘记密码自助重置仍按 v0.1.29 的行为工作。

## 升级说明

本版本不新增数据库迁移。安装脚本仍按版本校验并保留升级前备份。

## 验证与产物

通过 Go 测试、前端类型检查和构建，以及 CI 的 PostgreSQL/MySQL 检查。发布包包含 Linux amd64/arm64 二进制、Docker amd64/arm64 安装包、安装脚本和 SHA256 校验文件。
