# v0.1.2

探针页设备地址接口、账号 API 凭据与按元结算，并修复自绘下拉一律点不中选项的问题。

```sh
curl -fsSL https://github.com/kexue-aihao/Traffic-Forwarding-Panel/releases/download/v0.1.2/install-docker.sh -o install-docker.sh && sudo bash install-docker.sh
```

安装方式与 v0.1.1 相同：无需域名或交互输入，自动初始化 `admin`、生成随机密码并在安装完成时显示；默认服务地址 `http://127.0.0.1:18080`，数据目录 `/opt/traffic-forwarding-panel/data`，域名与 HTTPS 由 1Panel 配置。

## 本版内容

- **探针只给付费用户、只含本组设备**：有效套餐 + 设备组归属双重校验，非本人所属组返回 403；探针卡片补节点名、设备组与位置图标，普通账号看不到机器地址。
- **设备地址接口**：`GET /online/device/ip`（组内唯一设备）与 `GET /online/device/ip/list`（多台），另有 `/api/v1` 同义路径。带管理员签发的 API Token 即可取到该组机器当前地址，机器替换或换 IP 后同一接口返回新值；多台时单台接口返回 409 并提示改用列表。
- **账号与 API 凭据**：管理员建号后签发凭据、查看前缀与最近使用、重置或撤销。明文**只在创建或重置那一次返回**，服务端只存摘要；有效期二选一 —— 给 `expires_at`，或显式声明永久。凭据一律按普通用户权限处理，不继承管理员。
- **金额以元为单位**：站点设置的充值区间改为元（账本仍按整数分记账）；下单接受 `amount`（元），旧客户端的 `amount_cents` 继续兼容且不能同时给。支付通道可配额外手续费（百分比 + 固定值，加在充值金额之上、到账不变）与人民币兑 USDT 汇率，订单分别记录到账、手续费、实付与折算金额，回调按实付核对、按到账入账。
- **位置图标**：探针卡片按机器 IP 归属地显示几何基元绘制的 SVG 旗；查不到的码退回带码徽章，不冒充国旗。查询地址可在站点设置里换成自建服务，留空即关闭。

## 修复

- **下拉一律点不中选项**（用户反馈：网络诊断选不了 ping/tcping/mtr）：自绘列表里的选项不可聚焦，鼠标按下会把焦点从原生 select 上带走并触发 blur，组件在随后的 click 之前就收起了列表，点击落到列表底下的元素上。全站下拉都受影响，现已修复；键盘操作与自动化选值原本可用，因此此前未被测试发现。
- **顶栏下拉被内容盖住**：顶栏的毛玻璃层叠上下文与普通流位置使展开的列表会被内容区控件覆盖，三个浏览器引擎实测复现，已按层叠顺序修正。
- **网络诊断的节点下拉漏机器**：原来只取第一页（100 条），机器更多的部署会有节点不出现在列表里；改为分页取完。
- 不可选的占位项（如「选择渠道」）改为禁用样式，不再看着像能点。

## 升级

已安装的旧版按 [部署说明](https://github.com/kexue-aihao/Traffic-Forwarding-Panel/blob/v0.1.2/docs/docker-deployment.md) 备份后导入新镜像、更新 Compose；保留 `data/` 与管理员账号，不重新初始化。数据库迁移随启动自动执行：旧站点设置里以分写下的充值区间会按元读回，旧订单缺失的实付字段按到账金额补齐。

## 已知限制

- 位置查询默认启用公共服务 `https://ipwho.is/{ip}`，会把被查询的机器公网 IP 发给该服务；不需要的部署请在站点设置里留空关闭或换成自建服务。
- 加密资产的折算金额是**报价**：网关按其商户汇率结算，两边需配置同一汇率。
- 当前租约续期可能关闭旧连接；连接连续性、容量/性能工作，以及跨机、公网与真实支付的验收继续按原指示等待后续安排。
- 本版发布不改变上述验收边界，也不把尚未完成的 P0–P6 生产验收记为已通过。
