# v0.1.8

探针页面调整为接近监控表格的横向布局：节点名称和 ID、实时速率摘要、在线状态、IPv4/IPv6 区域、速率、开机时长、累计流量，以及 CPU、内存和磁盘资源条在同一行展示。桌面端保持紧凑横向排列，窄屏自动折叠为多列或单列；WebSSH、远程卸载、设备详情和历史趋势继续保留。

新增综合管理脚本，统一提供 Docker 服务安装、升级、卸载和管理员密码重置操作。现有部署可以使用项目文档中的完整一行命令下载脚本；升级会保留账号、数据库和配置，卸载默认保留数据库。

验证覆盖前端类型检查、生产构建，以及 Chromium、Firefox 和 WebKit 下的登录、探针历史、离线节点、重试、多视口和操作权限场景。
