# 流量连续性修复

2026-09-24，针对入口 Agent 的租约切换断流、同步通道相互阻塞和短暂计量队列拥塞处理。仅源码变更，不代表已发布新安装包或更新现有节点。

## 连接与租约

- 同一规则仅更换租约或刷新配置有效期时，保留 TCP 连接、UDP 会话和共享 TLS 路由。每次计量读取当前规则的租约与有效期，不继续使用建连时的旧租约。
- 计量记录仍绑定实际使用的租约及套餐周期；购买新周期后，同一连接的后续字节进入新周期，旧记录补传仍结算旧周期。
- 用量任务每秒检查租约。已消耗且剩余不超过 `min(租约字节数/8, 64 KiB)`，或配置/租约有效期不足15秒时，持久标记旧租约不再可用，补传最终用量、完成退租，再通知配置任务拉取新租约。
- 一个转发块装不进旧租约的剩余额度时，也会触发上述流程。若整个新租约都小于该块，则拒绝该块，避免剩余套餐额度不足时不断退租和重复分配。
- TCP 在额度切换或待报队列暂满时保留连接，等待恢复最多30秒；等待期间不发送未计量字节。恢复后只计量一次。超时、规则撤销或持久存储失败会终止转发。
- UDP 不因等待额度而阻塞同一监听器上的其他客户端。临时额度不足或待报队列满时丢弃当前报文，不计费并保留会话；原有30秒无响应会话回收仍然适用。
- 目标、身份、协议策略、资源限制等实际规则变化仍关闭原连接，确保撤销和降级生效。共享 TLS 父子路由也执行相同原则。

这保证租约切换不强制重建连接，不保证切换期间零停顿，也不保证 UDP 零丢包。没有签发新的额度时不能继续转发。

## 同步与背压

- 配置与 ACK：默认每5秒；退租成功额外触发一次配置拉取。
- 用量与退租：独立任务每1秒执行；待报记录达到100条或数据路径等待额度时提前唤醒。每批最多500条，减少积压时的 HTTP 请求和确认落盘次数。
- 探针：独立任务，默认每5秒。用量接口失败或挂起不会阻止探针或配置撤销。
- 各通道失败独立重试。用量通道仍严格遵守“确认全部记录后才能退租”，单条退租失败不阻止其他租约的退租尝试。
- Agent 的同步单周期入口 `Step` 保留确定性的执行次序并汇总错误；实际 `Run` 使用独立任务。运行中退出会取消并等待后台同步任务结束。
- 本地计量队列仍最多256条、每次组提交最多128条、待确认记录仍最多4096条。实际数据路径等待队列位置，不因短暂队列占满立即断开 TCP；取消后未执行的请求不消耗额度。
- 队列占满本身不再导致把所有有效租约提前退掉。

## 保留的账务约束

每个转发块仍在 WAL 同步落盘成功后才放行；本次没有改成仅内存计数或先发送后补记。因此磁盘吞吐仍会影响转发吞吐，持久化成功后实际发送失败的字节仍按原有保守口径计量。取消这项约束需要另外定义崩溃时的额度预留、发送确认和差额补偿协议，不能通过跳过 fsync 保证可靠计费。

商业租约仍最多5分钟/16 MiB加权预算；每节点账号带宽/连接/IP限制、倍率取整、重复上报去重及未知额度不返还等规则不变。长期面板失联、配额耗尽或磁盘不可用时仍停止放行。

## 验证与更新

新增回归覆盖：

- TCP 与 UDP 已有连接切换租约，旧账期与新账期分别计量。
- 同一 TCP 连接收发合计20 MiB跨过16 MiB商业租约，直连和 TLS + Mux 两条路径分别对账；同一连接购买新周期后继续收发。
- 实际共享 TLS 子规则连接在有效期和租约刷新后继续使用，在限制改变后关闭。
- 用量 HTTP 请求挂起时，探针继续发布，配置撤销关闭已有连接。
- 待报队列满后恢复、不提前退租、不重复计量，以及等待取消不消耗额度。
- 已过期租约不放行，续租后使用新有效期；无法容纳转发块的小额租约不会无限续租。

本机验证命令：

```sh
go test ./... -count=1
go test -race ./internal/agent ./internal/integration ./internal/tunnel ./cmd/agent -count=1
go vet ./...
```

没有数据库迁移、API 字段或 WAL 格式变化。重新构建并更新入口 Agent 即可使用；仅重启或更新面板不会替换现有入口进程。首次更新 Agent 进程本身仍会中断它持有的连接。生产 Linux 跨机吞吐、延迟与丢包条件需另外验收。
