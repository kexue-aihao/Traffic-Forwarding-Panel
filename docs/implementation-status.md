# 实施状态

更新：2026-09-21。本文记录实际实现及证据，不把需求目标当作验收结果。项目可在本机运行，完整 P0–P6 尚未交付。

## 已实现

| 范围 | 当前代码与边界 |
|---|---|
| 控制面与身份 | Go模块化服务；管理员/用户/节点身份分离；Cookie会话、密码更改/本机恢复、账号停用、节点凭据轮换；所有者范围API Token，尚无自定义细分角色 |
| 资源与配置 | 用户、设备组、节点注册、规则增改启停删除；节点/协议/端口唯一预留、版本冲突、应用ACK、待ACK释放；组协议策略及授权撤销 |
| 三库 | SQLite WAL与有界优先级写队列、PostgreSQL、MySQL；公共迁移锁及版本迁移；三库首版均为单控制面实例 |
| Agent与加密 | 独立Agent，四承载×TCP/UDP、直接转发、TLS1.3/证书和凭据验证；WS与HTTP CONNECT内层TLS；有限权益、断线缓存、持久未确认计量 |
| 链式 | 最多三个出口，四承载任意组合，逐跳白名单/证书/Token/稳定身份检查；地址与身份防环；仅首入口计业务流量。出口手动配置，尚无拓扑配置页面 |
| 计量持久化 | CRC32C/序号WAL、组提交、有界队列与补传；批量最多500条，商业结算与控制面记录同事务；重复/冲突、失败回滚、退租并发保护 |
| 探针 | 真实CPU/内存/磁盘/负载/网卡速率、公网IP来源记录；授权实时SSE，普通用户不返回真实公网IP；分钟7天、小时180天聚合，指标独立有效样本计数，缺测不补0 |
| 商业基础 | CNY整数分钱包与不可变账本；幂等充值/购买、购买成功立即重置周期和配额、上海自然月夹紧月末；旧周期迟到计量保留归属 |
| 支付 | EPay、原版EPUSDT、BEpusdt、TokenPay、Cryptomus固定协议适配器；持久创建意图、结果不确定状态、验签回调、人工主动查单；原版EPUSDT查单明确不支持 |
| 前端 | Vue/TS双入口、手写组件、明暗/六色、本地字体图标、嵌入/CSP；资源操作、实时与历史探针、商业分页、订单核对、刷新保留未确认支付意图、账号/Token页面 |
| 备份 | 一致性JSONL快照、整数精度保持、空库事务恢复、截断/非空目标拒绝；外部商户状态、证书/密钥、Agent状态需另外协调 |

当前商业配额租约每次最多5分钟/16MiB加权预算。只有已确认最终用量的退租才返还未使用额度；未知未用额度不重复分配。续租会重建规则监听及关闭旧连接，因此24小时是离线授权上限，当前商业租约不能据此宣称可无损离线运行24小时。

探针实时值与待落库历史使用有界内存。历史桶允许前一分钟迟到采样，约1–2分钟后落库；尚未关闭的监控桶在重启时可能丢失，数据库故障后重启也可能丢失待落库监控队列，日志会报告持久化故障。财务/原始计量走独立确认与WAL路径，不用探针曲线计费。

## 测试证据与环境

本机Windows、12逻辑CPU、约32GiB RAM；Go1.26.5、Node24；真实本机PostgreSQL18.6/MySQL8.4.6。测试创建随机隔离数据库，不以可连接数据库代替业务验证。

已运行的分模块验证：

- `go test ./internal/commerce ./internal/platform ./internal/storage -count=1`：SQLite、PostgreSQL、MySQL；并发购买、充值去重、旧周期用量、退租、端口/ACK、身份隔离、快照恢复；批量第3分块注入SQL失败后整批回滚、500条重放、4GiB增量和CAS冲突。
- `go test -race ./internal/tunnel ./internal/agent ./cmd/agent -count=1`：三跳64种承载组合TCP/UDP，逐跳证书/Token/目标失败，别名回环，断链清理、下游握手取消，入口只扣一次；此前的WAL崩溃边界及磁盘故障测试保留。
- `go test ./internal/platform -run ProbeHistory -count=1`：三库真实聚合/重试/权限撤销/留存；SQLite另运行race。
- `go test ./internal/payment -count=1`：供应商已公布向量、Cryptomus独立运行时向量、受信TLS模拟网关、超时/重定向/篡改/币种/重复字段。没有真实商户交易。
- 集成主线运行 `go test -race ./...`、`go vet ./...`，全通过；`CGO_ENABLED=0`的Linux amd64/arm64面板与Agent交叉编译通过。
- 主线 `npm ci`、`npm run typecheck`、`npm run build`通过，提交的嵌入产物零漂移；`npm test`及`npm run test:live`各自Chromium/Firefox/WebKit通过。fixture覆盖320/390/768/1440/1920、CSP/表单/过期响应/历史空值；live使用真实Go/SQLite及明示聚合夹具验证API/权限/历史UI，不冒充真实Agent采样实验。

四承载真实控制面→商业→Agent集成测试位于 `internal/integration/agent_test.go`；链式实传为Windows本机真实socket。交叉编译与回环实验不替代Linux两台实机和公网条件验收。

容量：`BenchmarkUsageCapacity`使用500节点、1万用户、10万规则、500批×200条计量，并核对三层10万事实及102,400,000字节；本轮顺序执行结果另记于 [容量冒烟记录](capacity-smoke.md)。未运行参考16vCPU环境独立压测机下2小时/24小时API+探针+计量混合负载，不宣称容量达标。
