| 探针页面能力 | CPU 型号/占用、内存、磁盘、虚拟交换、负载、网卡速率均已上报并展示；新增按国家/地区码绘制的位置图标 | 旗面是几何基元拼的近似图形，认不出的码退回带码徽章，不冒充国旗 |

| 通道汇率与手续费 | 每条支付通道可配 `fee_percent/fee_fixed`（加在充值金额之上，到账不变）与 `rate/crypto_currency`（折算应付 USDT）；订单新增 `payable_cents/fee_cents/payable_crypto`，回调按实付核对、按到账入账 | 折算金额是报价：网关仍按其商户汇率结算，两边需配同一汇率 |
| 自绘下拉：选项点不中（用户反馈：网络诊断选不了 ping/tcping/mtr） | `Select.vue` 里选项的 `<li>` 不可聚焦，按下鼠标会把焦点从原生 `<select>` 上带走并触发 `blur`，组件在随后的 `click` 之前就收起了列表，点击落到列表底下的元素上 —— 选项加 `@mousedown.prevent` 保住焦点，`onBlur` 改为只在焦点离开组件时收起；另发现顶栏下拉会被内容区控件盖住（三引擎实测），给顶栏补 `position:relative;z-index` | 修复前只有 `selectOption` 这类直接改原生 select 的自动化路径能通过，真实点击测不出来；本轮把浏览器用例改成点击真实选项，覆盖页面、弹窗与顶栏三处 |
| 网络诊断的节点下拉漏机器 | 该页原来只取 `/nodes?page_size=100` 的第一页，机器超过 100 台时后面的不会出现在下拉里（操作方只会以为「这台选不了」）；改为按 `total` 分页取完，与探针页的历史选择器同一做法。造 130 台实测：下拉列出 130 项 | 只影响这一处的候选列表，接口、鉴权与权限未变 |

本轮实际运行：`go test ./... -count=1`、`go vet ./...` 全通过（含新增的 `internal/contract` 金额/站点换算、`internal/commerce` 手续费与汇率、`internal/platform` 凭据/设备地址/位置解析测试）；`npm run typecheck`、`npm run build`、`npm test`（Chromium/Firefox/WebKit）与 `npm run test:live`（真实 Go/SQLite 控制面，新增设备地址接口与管理员签发凭据的端到端断言）在三个引擎通过。浏览器用例里的下拉切换已改成点击真实选项（页面、弹窗、顶栏、网络诊断各一处）：把 `@mousedown.prevent` 撤掉即复现「选项点不中」，说明这一条确实在测那条路径。位置查询默认启用公共服务 `https://ipwho.is/{ip}`，运营方可在站点设置里换成自己的服务或留空关闭；测试中显式关闭，不外发任何地址。

当前商业配额租约每次最多5分钟/16MiB加权预算。只有已确认最终用量的退租才返还未使用额度；未知未用额度不重复分配。当前源码在仅租约变化时保留 TCP 连接、UDP 会话及共享 TLS 路由，后续字节使用新租约；TCP 等待额度或待报队列恢复最多30秒，期间不允许使用过期额度。配置、用量与探针独立同步，详见 [流量连续性修复](traffic-continuity.md)。24小时仍只是配置授权上限，不能据此宣称商业租约可离线运行24小时。

探针实时值与待落库历史使用有界内存。历史桶允许前一分钟迟到采样，约1–2分钟后落库；尚未关闭的监控桶在重启时可能丢失，数据库故障后重启也可能丢失待落库监控队列，日志会报告持久化故障。财务/原始计量走独立确认与WAL路径，不用探针曲线计费。

- Webhook 订阅、事务事件 outbox、HMAC-SHA256 签名与稳定事件 ID；公网 HTTPS 直连、禁止重定向、逐次 DNS 地址检查并固定连接 IP，最多12次投递、30天通知留存。金额保持十进制字符串；外部投递失败不回滚已提交财务，outbox 持久化失败会回滚同一事务。删除订阅阻止后续调度，已发出的请求可能完成。
- 组内每用户规则数量限制在事务锁内检查；控制面状态诊断覆盖账号、组授权、启用、心跳、ACK 和租约过期。另提供 Agent 实际执行的 TCP 规则 DNS/连接/隧道诊断，绑定当前规则和有限授权。

## 套餐限制续接

commerce v4增加独立套餐限制与权益限制快照表。规则数按账号跨组/跨节点计数，停用规则也占用名额，普通创建和导入共享账号行锁；降级后按规则ID升序保留前N条可下发规则，其余保留供用户删除/调整。限制撤销在节点下一次拉取配置生效；离线节点仍受既有有限租约约束。

连接数、活跃IP和带宽按同一账号在单个入口节点的全部规则合计，不承诺跨节点全局合计。TCP连接、UDP客户端地址/端口会话各计1；目标和链式中间跳不重复计数。IPv4映射IPv6地址统一去重；IP在最后一个活动会话关闭后释放，TCP空闲2分钟、UDP无响应30秒关闭。合计带宽单位B/s，令牌桶突发量为 `min(max(rate/10,65535),1048576)` 字节；TCP等待额度，UDP额度不足丢弃且不计费。刷新配置和续租不补满突发量；进程重启允许一个初始突发量。0代表无商业限制，独立安全上限仍保留。

新Agent声明 `resource-limits-v1`；缺少能力的节点不接收带限制的规则，升级后的ACK更新能力并生成新配置版本后恢复下发。能力不足的节点无法启用受限规则，规则诊断同时显示能力不足和套餐规则名额不足。旧权益无该快照时保持原有限制为0，编辑套餐不追溯改变既有权益；新购买和兑换保存当时限制，叠加包不改变限制。

## 状态告警与通知设置续接

- 增加持久离线/恢复状态和权益告警检查点，状态与事件/outbox同事务；重启和重复扫描不重复通知。默认失联90秒、持续恢复15秒且收到后续心跳；面板启动后额外等待一个离线宽限期供Agent重连。此处告警表示面板收不到心跳，不能据此断言节点物理故障。
- 默认到期前72小时提醒、剩余已确认流量不超过10%提醒，到期后通知。每个权益周期每类一次；新权益重新计数，叠加包不重置已发送标记。额度按真实已结算量计算，分配未用租约不算已使用流量。
- 管理员可以版本化修改阈值和启停状态告警。每10秒扫描最多1000节点和1000个当前权益，超过时分页轮转，扫描耗时还受数据库负载影响；不能把它宣称为所有规模的10秒告警保证。
- 通知地址可选择事件、启停或静默（API最多30天，页面提供一小时和解除）；静默/停用期间保留事件但不补发，对已有待投递记录做终止标记。已经发出的请求可能完成，迟到的响应不能恢复被静默的任务。
- 普通用户仅有当前授权节点的事件；查询与实际投递再次复核授权。管理员Cookie创建的订阅可接收全局节点告警，普通资源API Token创建的订阅及事件查询仍仅按设备组授权。事件不携带真实IP、隧道凭据或原始Agent错误。
- 事件/投递明细仍保留30天，独立去重检查点不随通知清理删除；财务记录不受影响。运营页面增加最近事件、告警策略及通知设置。

## 功能补齐与预发布（2026-09-21）

- 规则普通保存与导入共用事务校验；预览使用保存点模拟并最终回滚，覆盖批内冲突、授权和配额；`update_by_port` 按所属用户/节点/网络/端口匹配，执行复核预览版本。

## 探针列表、WebSSH 与远程卸载（v0.1.7）

探针改为紧凑设备行，显示运行时长、上下行速率、累计上下行与 CPU/内存/磁盘进度条。未知值保留未知，历史趋势保留在列表下方。累计流量是非回环网卡的系统计数（可能包含虚拟网卡重复流量），随重启/网卡重置变化，不用作转发计费；按 1024 进位至 TB/PB/EB。

管理员可在探针行打开 WebSSH。它通过既有 Agent 出站通道提供 Linux PTY 交互终端，不依赖开放 22 端口或保存 SSH 密码；支持持续目录、交互程序、Ctrl+C 与窗口缩放。复用管理员 Cookie、二次密码验证和最长 10 分钟会话；取消、授权失效或连接关闭时终止会话。保留会话创建/领取/结果审计，不记录可能含密码的原始按键；原逐条命令终端的命令审计仍保留。

远程卸载仅支持官方脚本默认目录的 root/systemd 安装。先拒绝有转发规则（包括停用规则及等待停止确认的规则）或被规则使用的出口组节点；领取任务后保留卸载占用，禁止新增规则和出口。Agent 确认空配置并补交流量后，由独立持久 systemd 服务停止 Agent/出口、删除已知受管文件和节点身份、回传结果。面板仅在成功回传后移除设备列表项，保留历史流量与审计。待领取任务可以取消；领取后的卸载不再取消/超时重派，重连复用同一任务凭据。回传失败由服务重试；磁盘/服务操作失败时保持“等待结果”，可在机器运行 `journalctl -u tfp-agent-uninstall` 排查。用户自备证书和其他目录文件保留。

更新面板后，旧 Agent 需重新执行该设备组的接入命令以更新程序和服务参数；已有节点身份保留。新安装脚本启用 `-enable-terminal -enable-uninstall`；自行部署的 Agent 默认不启用，非默认状态目录不开放远程卸载。卸载完成后重新接入将创建新节点身份。

验证用例包括三浏览器列表/权限/按键与尺寸消息、PTY 的目录保持/中断/缩放、操作凭据与取消、未确认卸载不得隐藏、删除等待 ACK、卸载占用与幂等回传。`scripts/test_agent_uninstall.py` 在独立 Linux CI 机器安装真实 systemd Agent，并模拟回传失败，检查服务/文件清理、重试确认、用户证书保留与设备列表移除。
